# Planification MYTHORIA

Mythoria est un jeu de cartes à collectionner dans un univers fantastique.
La livraison intermédiaire comprend l’accueil et la boutique avec un panier simple.

| Page | État prévu pour le 22 octobre |

| html/index.html | Présentation du jeu, des types, des boosters et des légendaires |
| html/shop.html | Boutique et panier fonctionnel |
| html/opening.html | Page réservée, sans fonction d’ouverture |
| html/grimoire.html | Page réservée, sans gestion de collection |
| html/deck.html | Page réservée, sans construction de deck |

Le projet complet prévoit cinq pages. Échéance globale : 27/10/2026 à 11 h 59.
